# Package index

## Import and batting statistics

- [`import_scorecards()`](https://kwoolaid725.github.io/msds-457/reference/import_scorecards.md)
  : Import a play-level scorecard CSV
- [`calculate_batting_stats()`](https://kwoolaid725.github.io/msds-457/reference/calculate_batting_stats.md)
  : Calculate batting statistics from reviewed plays

## Run value

- [`calculate_run_impact()`](https://kwoolaid725.github.io/msds-457/reference/calculate_run_impact.md)
  : Calculate run expectancy added for verified events
- [`plot_run_impact()`](https://kwoolaid725.github.io/msds-457/reference/plot_run_impact.md)
  : Plot total run impact by player

## Personal season comparison

- [`season_games()`](https://kwoolaid725.github.io/msds-457/reference/season_games.md)
  : Build a team's reference season from an MLB schedule
- [`compare_personal_season()`](https://kwoolaid725.github.io/msds-457/reference/compare_personal_season.md)
  : Compare a personal game collection with a reference season

## Datasets

- [`reviewed_scorecards`](https://kwoolaid725.github.io/msds-457/reference/reviewed_scorecards.md)
  : Five reviewed team scorecards matched to MLB game records
- [`reviewed_base_out`](https://kwoolaid725.github.io/msds-457/reference/reviewed_base_out.md)
  : Base-out transitions for the five reviewed scorecard teams
- [`run_expectancy_fangraphs`](https://kwoolaid725.github.io/msds-457/reference/run_expectancy_fangraphs.md)
  : FanGraphs run expectancy matrix
- [`reviewed_team_seasons`](https://kwoolaid725.github.io/msds-457/reference/reviewed_team_seasons.md)
  : Full regular seasons for the five reviewed scorecard teams
- [`twins_scorecard_2024`](https://kwoolaid725.github.io/msds-457/reference/twins_scorecard_2024.md)
  : Minnesota Twins scorecard entries from April 29, 2024
- [`demo_scorecards`](https://kwoolaid725.github.io/msds-457/reference/demo_scorecards.md)
  : Fictional scorecard plays for learning and testing
